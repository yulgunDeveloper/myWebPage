# 권유림 · Developer Portfolio

Java와 Spring을 중심으로 서비스를 만드는 개발자 권유림의 포트폴리오입니다.

## 홈페이지

**[포트폴리오 바로 보기 ↗](https://yulgundeveloper.github.io/myWebPage/)**

크림, 파우더 블루, 라벤더, 블러시 핑크를 사용한 반응형 홈페이지입니다. 프로젝트 상세 보기, 기술 스택, 자격증, 연락처를 확인할 수 있습니다.

- [GitHub 프로필](https://github.com/yulgunDeveloper)
- [기술 블로그](https://yulgun-dev.tistory.com/)
- 이메일: green4652@naver.com

## 파일 구성

- `index.html`: 홈페이지 내용
- `style.css`: 스타일 및 반응형 레이아웃
- `script.js`: 프로젝트 상세 보기 및 이메일 복사

빌드 없이 정적 호스팅으로 실행할 수 있습니다. 기존 `portfolio.html` 주소도 새 홈페이지로 연결됩니다.
