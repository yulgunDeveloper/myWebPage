02 / ABOUT & STACK현장의 데이터를 다루는 웹 개발자

데이터를 이해하고,
업무의 맥락을 읽습니다.

Java와 Spring을 기반으로 에너지 데이터와 웹 애플리케이션을 연결하는 개발자 권유림입니다. 전남 신재생발전 지역 관제시스템(LRMS) 사업의 세부 시스템 개발에 참여하며, 기상 데이터 연계·적재와 발전량 예측·실측 비교, 발전·예측 데이터 분석 기능을 구현했습니다.

데이터가 어디에서 들어와 어떤 조건으로 처리되고, 운영자가 어떤 화면에서 확인하는지까지 함께 생각합니다. 데이터베이스와 백그라운드 프로세스, 표와 차트로 이어지는 흐름을 구현해 왔습니다.

03 / INDUSTRY CONTEXT프로젝트가 놓인 산업의 맥락

왜, 이 데이터를
연결해야 했을까요.

날씨에 따라 달라지는 재생에너지를 안정적으로 활용하려면,
데이터 수집과 예측, 운영 판단을 잇는 시스템이 필요합니다.

JEONNAM / RENEWABLE ENERGY

분산된 발전원을,
하나의 관제 흐름으로.

태양광·풍력은 날씨에 따라 발전량이 달라집니다. 한전은 광주·전남 지역에서 재생에너지의 출력 예측, 수용 한계량 산정, 출력 제어를 연결하는 LRMS를 개발해 왔습니다.

한전은 2025년 6월 광주·전남 LRMS 준공을 발표했습니다. 이 사업에 포함된 세부 시스템을 개발하며, 기상 데이터 연계·적재와 발전·예측 데이터 비교·분석을 담당했습니다.

광주·전남 LRMS 사업 배경 ↗
  1. 01

    수집

    기상과 전력 데이터를 확보합니다.

  2. 02

    발전량의 변화와 실제값의 차이를 살펴봅니다.

  3. 03

    운영 지원
